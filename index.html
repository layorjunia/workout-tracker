Apple Health sync

Syncs HR, sleep, active energy, and steps from your iPhone Health app to a private GitHub Gist a few times a day. Show setup instructions →

One-time setup

  1. Make a GitHub Personal Access Token at github.com/settings/tokens → "Generate new (classic)" → check the gist scope. Copy it.
  2. Create an empty secret Gist at gist.github.com: filename health.json, content {}, click "Create secret gist". Copy the long ID from the URL.
  3. Paste the Gist ID in the field above.
  4. Install the Shortcut on your iPhone (see README — needs ~6 actions: get health samples, build JSON, PATCH the Gist).
  5. Add an iOS Automation for "Time of Day" repeating at 7 AM / 12 PM / 6 PM / 10 PM, action = Run Shortcut. Toggle off "Ask Before Running".
